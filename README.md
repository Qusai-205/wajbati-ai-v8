# Wajbati AI V8

نسخة مطوّرة من مستشار المطعم مع Agent محلي قوي + دعم Agent حقيقي من الخادم عند توفير `OPENAI_API_KEY`.

## Submission build

- يتضمن تحديث Agent V10 لفهم أفضل للأسئلة القصيرة والعامية والمقارنات مثل أقل سعر، الأسعار، جاج، شورما، سمك، والمشروبات.
- يدعم إلغاء الطلب من جهة الزبون مع حفظ سبب الإلغاء وإظهاره في صفحة الأدمن.
- المنيو والطلبات والحالات مرتبطة بقاعدة Supabase المشتركة.

## أهم ما تغيّر في V8

- قاعدة نوايا محلية تغطي **292 صياغة تدريبية موزعة على 40 نوع سؤال** بالعربية الفصحى، العامية والإنجليزية.
- اختبار آلي على بنك الأسئلة: **292/292 أعطت ردًا** بدون سقوط للمحادثة.
- إذا سأل الزبون عن **المشروبات / مشرايب / drinks** أو الحلويات أو المقبلات أو السلطات أو الوجبات، يعرض **كل الأصناف المتاحة في القسم بدون حذف**.
- يفهم أسئلة تفاصيل الصنف: المكونات، طريقة الطبخ، طريقة التقديم، الطعم، الحار، حجم الحصة، وقت التحضير، التعديلات، الاقتراحات الجانبية، السعر، السعرات، البروتين، الكربوهيدرات، الدهون والحساسيات.
- ذاكرة جلسة لأسئلة المتابعة: مثال: «شو مكونات الشاورما؟» ثم «كيف بتنطبخ؟» ثم «كيف بتقدموها؟».
- قراءة المنيو الحية في كل سؤال. أي صنف جديد يضيفه الأدمن يصبح متاحًا للمستشار فورًا.
- بيانات أوسع لكل صنف في صفحة الأدمن، بما فيها الاسم الإنجليزي والكلمات البديلة وطريقة الطبخ والتقديم والحصة والوقت والتعديلات والـ Pairing.
- حقول إنجليزية متقدمة اختيارية للأصناف حتى تكون إجابات الوضع المحلي دقيقة بالإنجليزية أيضًا.
- معلومات مطعم إضافية: حلال، التدخين، الحيوانات الأليفة، Dress code، الجلسات الخارجية، الرسوم والخدمة وغيرها.
- قاعدة السعرات المرفوعة ما زالت مدمجة، مع دعم أسئلة مثل: `how many calories are in a banana?`.

## التشغيل

### أسهل طريقة على Windows
شغّل:

`start.bat`

ثم افتح:
- الزبون: `http://localhost:4173`
- الأدمن: `http://localhost:4173/admin`

يمكن أيضًا فتح `index.html` مباشرة؛ سيعمل الـAgent المحلي بدون إنترنت.

## تشغيل AI حقيقي اختياريًا

إذا تم ضبط متغير البيئة `OPENAI_API_KEY` قبل تشغيل `server.js`، سيستخدم الموقع نموذج AI من الخادم، مع إرسال المنيو الحالية ومعلومات المطعم والطلب وسياق المحادثة في كل سؤال. إذا لم يوجد مفتاح أو فشل الاتصال، يعود تلقائيًا إلى Agent V8 المحلي ولا تتوقف المحادثة.

## ملاحظة مهمة عن الدقة

الـAgent لا يخترع بيانات خاصة بالمطعم. أي معلومة مثل طريقة طبخ صنف جديد أو طريقة تقديمه يجب أن تكون مسجلة من الأدمن، لذلك تمت إضافة حقول تفصيلية كثيرة في صفحة إدارة المنيو.
